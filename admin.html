Write a tracking algorithm

Takes a few frames from the live camera and asks Claude to write a tracker for the markers it can actually see, using the current calibration as a starting point. The result is saved as a new algorithm you can review and then select on the console.

The camera must be streaming. Generated code is not switched on automatically — read it first. It runs on this machine with the same access as the rest of the server.
